Tutorial completo

Deutsch A1 PT Learning Coach

Guia prático para instalar, executar e usar a app que ensina alemão A1 a partir do zero, com explicações em português europeu, exercícios, revisão espaçada e diagnóstico adaptativo.

A app funciona localmente. Não precisas de APIs pagas. O áudio com gTTS pode precisar de internet, mas o resto da aprendizagem funciona com dados locais e SQLite.

1. O Que Esta App Faz

Ensina A1 do zero

Cumprimentos, apresentação, artigos, verbos, perguntas, comida, cidade, rotina e revisão.

Explica em português

A interface e as explicações são pensadas para um falante português.

Corrige exercícios

Mostra resposta certa, explicação e tipo de erro.

Adapta o estudo

Detecta tópicos fracos e recomenda o que praticar a seguir.

3. Setup Do Zero

Entrar na pasta do projeto 
cd /Users/carlosferreira/Projecto/Deutsch_A1_PT_Learning_Coach
Criar ambiente virtual 
python3 -m venv .venv
Ativar ambiente virtual 
source .venv/bin/activate
Instalar dependências 
pip install -r requirements.txt
Executar a app 
streamlit run app.py
Depois abre o endereço local mostrado pelo Streamlit. Normalmente será http://localhost:8501. Neste momento, nesta máquina, a app foi aberta em http://localhost:8503.

5. Como Usar A App No Dia A Dia

Vai ao Início

Vê progresso A1, palavras para rever, tópico fraco e recomendação do dia.

Abre Aprender A1

Segue os módulos pela ordem: primeiros passos, eu e os outros, frases simples, família, comida, cidade e rotina.

Treina Vocabulário

Usa os flashcards. Dá atenção aos artigos der, die e das.

Faz Exercícios

A app corrige e guarda os erros. É assim que o motor adaptativo aprende onde tens dificuldade.

Faz Revisão Espaçada

Revê as palavras vencidas. Usa os botões: Não sabia, Difícil, Médio, Fácil.

Consulta Diagnóstico

Vê os tópicos fracos, tipos de erro e recomendação personalizada.

7. Como Interpretar O Progresso

Progresso A1

Estimativa geral baseada em precisão, vocabulário aprendido e quantidade de prática.

Precisão

Percentagem de exercícios certos. Acima de 80% é bom sinal.

Tópico fraco

Área com menor mastery score. Deve ser a prioridade.

Revisões hoje

Itens vencidos na revisão espaçada. Faz isto antes de matéria nova.

O objectivo não é ter 100% todos os dias. O objectivo é errar, corrigir, repetir e reduzir os mesmos erros ao longo do tempo.

8. Como Funciona A Revisão Espaçada

A revisão usa uma versão simples do algoritmo SM-2:

BotãoSignificadoO que acontece
Não sabiaFalhaste ou não te lembravas.Volta muito em breve.
DifícilAcertaste com esforço.Intervalo curto.
MédioAcertaste de forma aceitável.Intervalo médio.
FácilSabias bem.Intervalo maior.

9. Como Adicionar Vocabulário

Edita o ficheiro:

data/seed_vocabulary_a1.csv

Formato:

german,portuguese,article,plural,word_type,topic,level,example_de,example_pt,pronunciation_hint,difficulty
Exemplo 
Bahnhof,estação de comboios,der,Bahnhöfe,noun,transporte,A1,Ich gehe zum Bahnhof.,Eu vou para a estação.,bán-hof,1

Se a base SQLite já existir, apaga data/deutsch_a1.db para recarregar os seeds do zero.

10. Como Adicionar Exercícios

Edita:

data/seed_exercises_a1.csv

Tipos úteis:

  • multiple_choice
  • fill_blank
  • translation_de_pt
  • translation_pt_de
  • article_choice
  • verb_conjugation
  • order_words

11. Reset Do Progresso

Para recomeçar do zero:

rm data/deutsch_a1.db
streamlit run app.py
Isto apaga respostas, mastery score, revisão e histórico. Os ficheiros seed continuam guardados.

12. Testes

Para validar a app:

source .venv/bin/activate
pytest

Os testes verificam vocabulário, gramática, revisão espaçada, correcção, motor adaptativo e tradução fallback.

13. Problemas Comuns

ProblemaSolução

Porta ocupadaUsa streamlit run app.py --server.port 8503.
Áudio não funcionaO gTTS pode precisar de internet. Continua a usar texto e pronúncia escrita.
Quero recarregar seedsApaga data/deutsch_a1.db e executa de novo.
Erro em dependênciasReativa a venv e corre pip install -r requirements.txt.
